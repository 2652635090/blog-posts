# GitHub 文章完整示例

这篇示例展示了使用 front matter 配置文章元信息的方法。

## front matter 说明

在 Markdown 文件顶部用 --- 包裹 YAML 格式的元信息：

- title：文章标题
- date：发布日期
- category：分类
- tags：标签数组
- excerpt：摘要

这样博客页面就能正确展示标题、日期、分类和标签了。
